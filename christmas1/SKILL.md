# 크리스마스1 — 크리스마스 6×6 이모티콘 시트 제작

## 목적
사용자가 현재 대화에 직접 올린 캐릭터 이미지를 기준으로, 크리스마스·산타·루돌프·트리·눈·간식·파티 등의 장면을 36종 구성하고 정사각형 6열×6행 단일 시트를 만든다. 기본 멘트·장면은 `references/christmas-scenes.md`의 원본 58개에서 가져온다.

## 사용법
- `크리스마스1`: 스킬 안내 또는 제작 준비를 확인한다.
- 캐릭터 이미지를 첨부하고 `크리스마스1 이미지만들어`: 즉시 기본 36종 제작한다.
- `크리스마스1 멘트: ...`처럼 멘트를 주면 해당 표현을 우선 적용한다.
- 이미지를 생성할 도구가 없으면 결과물 생성이 불가능함을 알리고, 가능한 입력/장면 구성만 제공한다.

## 필수 규격 (원본 준수)
1. 1:1 정사각형 전체 시트, 6열×6행, 정확히 36개 동일한 정사각형 셀.
2. 셀 간 간격 0px. 내부 가로선 5개·세로선 5개만 1px 불투명 `#dddddd`로 배치. 외곽 테두리·외곽 여백·그림자·둥근 카드형 프레임 금지.
3. 전체 및 모든 셀 배경은 순백색 `#ffffff`. 투명·그라데이션·패턴 배경 금지.
4. 각 셀 상단 중앙에 정확히 하나의 멘트. 멘트는 검정 `#000000`, 동글동글하고 굵은 한글 서체. 길면 동일한 표현을 최대 두 줄로 나눌 수 있다. 추가 설명·효과음·번호·로고·워터마크는 쓰지 않는다.
5. 각 셀 상하좌우 5% 내부 안전영역을 확보한다. 텍스트·캐릭터·소품이 칸 경계나 구분선을 침범하거나 잘리지 않도록 한다.
6. 사용자가 현재 대화에 직접 올린 한 장의 기준 캐릭터만 참고한다. 얼굴·눈·머리·체형·의상·액세서리·선·채색·질감 등의 정체성을 36칸에서 유지한다. 현재 대화에 없는 기존·웹 이미지는 캐릭터 기준으로 쓰지 않는다.
7. 멘트가 각각 하나씩 정확하게 보이도록 한글 철자·띄어쓰기·누락·중복·깨짐을 검사한다. 사용자가 지정한 멘트는 임의로 바꾸지 않는다.
8. 각 셀은 서로 구분되는 감정·표정·자세·행동으로 제작하며, 장면 속 장식도 흰 바탕을 유지하는 최소한의 소품만 사용한다.

## 멘트 선택 우선순위
- 사용자가 정확히 36개를 제공하면 입력 순서대로 왼쪽 위→오른쪽 아래에 배치한다.
- 1~35개면 주제·말투를 유지하면서 부족한 멘트를 원본 라이브러리에서 중복 없이 보충한다.
- 사용자가 제공한 멘트가 없으면 아래 기본 36종을 사용한다. 각 멘트의 연출은 `references/christmas-scenes.md`와 매칭한다.
- 37개 이상을 제공하면 36개를 선택하도록 요청한다. 원본 참고 라이브러리에 58개가 있다는 것은 선택 대상이 58개라는 뜻이며 최종 시트 수량은 항상 36개다.
- '글자 없음' 요청 시에는 이 스킬의 필수 멘트 규칙과 충돌한다고 설명하고, 별도 방식이 필요하다고 안내한다.

## 기본 크리스마스 36종 (6행×6열)
- 1행: 메리 크리스마스! / 크리스마스가 왔어요! / 산타가 왔어요! / 선물 왔어요! / 선물 받아요! / 선물은 나야!
- 2행: 산타 기다리는 중 / 산타 언제 와? / 산타야 빨리 와! / 산타 출발! / 루돌프 출동! / 내가 루돌프!
- 3행: 산타 변신! / 메리메리 크리스마스 / 해피 크리스마스! / 행복한 성탄절! / 크리스마스 최고! / 크리스마스 좋아!
- 4행: 트리 꾸미자! / 트리 완성! / 반짝반짝 트리 / 별 달아줘! / 예쁘게 꾸몄지? / 캐럴 틀어줘!
- 5행: 캐럴 듣는 중 / 징글벨 징글벨 / 눈이 와요! / 첫눈이다! / 눈사람 만들자! / 눈사람 완성!
- 6행: 추워요! / 따뜻한 크리스마스 / 핫초코 한잔? / 쿠키 먹을래? / 케이크 먹자! / 크리스마스 파티!

## 실행 절차
1. 현재 대화의 가장 최근 이미지 또는 사용자가 지정한 업로드 이미지를 확인한다. 기준 이미지가 없다면 업로드를 요청한다.
2. 이미지의 실제 외형에서 고유 특징을 추출하고, 확인되지 않은 세부 특징은 만들어내지 않는다.
3. 36개 멘트와 `references/christmas-scenes.md`의 해당 묘사를 매칭해 36개 상이한 장면을 구성한다. 원본 묘사에 다른 인물이 등장하더라도 사용자가 업로드한 캐릭터 수와 정체성을 우선한다.
4. 사용 가능한 이미지 생성 기능으로 시트 이미지를 만든다. 구성 제어가 가능한 도구라면 격자·구분선·글자는 별도의 정확한 렌더링 공정으로 마감한다.
5. 6×6 배치, 각 칸 한 멘트, 글자 오류, 순백 바탕, 1px 내부 선, 안전영역, 캐릭터 일관성을 검수한다. 미달 시 수정한다.
6. 사용자 명령이 `이미지만들어`이면 설명을 최소화하고 최종 시트 한 장만 제시한다.

## 예외 안내
- 이미지가 없을 때: `기준으로 사용할 캐릭터 이미지를 업로드해 주세요.`
- 이미지가 있으나 콘셉트와 멘트가 없는 경우: 이 스킬은 기본 크리스마스 콘셉트와 기본 36개를 제공하므로 바로 제작할 수 있다.
- 36개 초과의 사용자 지정 멘트: `입력한 멘트가 36개를 초과했습니다. 사용할 멘트 36개를 지정해 주세요.`
- 사용자가 다른 배경을 요구하면 원본 규칙의 흰색 고정 사항을 알린다.

## 주의
이 스킬은 원본 문서에 등장하는 작가 경력·승인 건수를 실제로 검증하거나 보증하지 않는다. 6×6 36칸 시트는 카카오 플랫폼의 개별 업로드 규격 충족이나 승인 자체를 보장하지 않는다.
